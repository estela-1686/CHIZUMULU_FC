# 치주물루 유나이티드 FC 팬 사이트

GitHub Pages에 올려 쓰는 사이트예요. 서버나 결제가 필요 없어요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 사이트 전체 (디자인·기능·기본 내용) |
| `apps-script/Code.gs` | 후원·제안 신청서를 구글 시트에 저장하고 이메일로 알리는 코드. **GitHub에는 그냥 같이 올려 두기만 하면 되고**, 실제로는 구글 Apps Script에 붙여 넣어 써요. (5번) |
| `.nojekyll` | GitHub Pages가 파일을 그대로 쓰게 하는 빈 파일 |
| `data.json` | 처음엔 없어요. 관리자 모드에서 **게시하기**를 누르면 자동으로 생겨요. |

---

## 1. GitHub에 올리기 (약 5분)

1. [github.com](https://github.com) 로그인 → 오른쪽 위 `+` → **New repository**
   - Repository name: 예) `chizumulu-fc`
   - **Public** 선택 → **Create repository**
2. 새 저장소 화면에서 **uploading an existing file** (또는 Add file → Upload files)을 눌러요.
3. 이 폴더의 파일과 폴더를 **모두** 끌어다 놓아요: `index.html`, `README.md`, `.nojekyll`, `apps-script` 폴더
   - `.nojekyll`이 안 보이면 숨김 파일 보기를 켜세요. 없어도 사이트는 동작해요.
4. **Commit changes**를 눌러요.

## 2. 사이트 공개하기 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **main** / **(root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 떠요.
   - 예) `https://내아이디.github.io/chizumulu-fc/`

## 3. GitHub 토큰 만들기 (처음 한 번)

토큰은 사이트가 **게시하기**로 GitHub에 내용을 저장할 때 쓰는 열쇠예요.

1. [새 토큰 만들기](https://github.com/settings/personal-access-tokens/new) (Fine-grained token)
   - Token name: `cufc-site`
   - Expiration: **1년** 정도
   - Repository access: **Only select repositories** → 사이트 저장소 하나만
   - Permissions → Repository permissions → **Contents: Read and write**
2. **Generate token** → 나온 `github_pat_...` 값을 복사해요.
   - 창을 닫으면 다시 볼 수 없으니 4번을 바로 하세요.

## 4. 처음 설정 — 대표 관리자 만들기

1. 공개된 사이트 맨 아래 **관리자**를 누르면 **처음 설정** 창이 떠요.
2. 입력할 것:
   - **이메일** — 신청서 알림을 받을 주소
   - **아이디**
   - **비밀번호** — 10자 이상
   - **GitHub 토큰** — 3번에서 복사한 값
   - **GitHub 아이디·저장소 이름** — github.io 주소에서 열면 자동으로 채워져요
3. **만들고 게시**를 누르면 끝이에요. 이제부터는 아이디·비밀번호로 로그인해요.

> 토큰과 이메일은 **관리자 비밀번호로 잠긴 상태**로만 저장돼요. 비밀번호 자체는 어디에도 저장되지 않아요.

## 5. 후원·제안 신청서를 이메일로 받기 (약 10분, 무료)

방문자가 "후원 · 제안 → 제안하기"에서 신청하면 이렇게 돼요.
- 구글 시트에 저장돼요.
- 등록된 관리자 모두에게 이메일이 가요.
- 관리자 모드의 **⚙ 관리자 → 후원 · 제안 신청** 탭에 나타나요.

**연결 방법** (사이트의 ⚙ 관리자 → 게시 · 이메일 설정에도 같은 안내가 있어요)

1. [새 구글 시트](https://sheets.new)를 만들고 이름을 `치주물루 신청서`로 정해요.
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 편집기에 있던 코드를 모두 지우고 코드를 붙여 넣은 뒤 저장(💾)해요.
   - 코드는 사이트 설정 화면의 **코드 복사** 버튼으로 복사하거나, `apps-script/Code.gs` 내용을 그대로 써요.
4. 오른쪽 위 **배포 → 새 배포**에서 아래처럼 정하고 **배포**를 눌러요.
   - 톱니바퀴 → **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
5. 권한을 허용해요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누르세요.
   - 회원님이 직접 만든 스크립트라서 나오는 경고예요.
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 사이트의 **게시 · 이메일 설정**에 붙여 넣고 **연결하기** → **지금 게시**를 눌러요.
7. **테스트 메일 보내기**로 메일이 오는지 확인해요.

**알아 두세요**
- **메일 한도:** 구글 무료 계정은 하루 약 100통까지 메일을 보낼 수 있어요.
- **시트에서도 관리:** 신청 내용은 구글 시트에서도 보고 정리할 수 있어요.
- **처음부터 다시 연결할 때:** Apps Script 편집기에서 `resetConnection` 함수를 한 번 실행한 뒤 다시 연결해요.
- **코드를 바꿨다면:** **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영돼요.

## 6. 관리자 추가·관리 (GitHub 필요 없음)

**⚙ 관리자 → 관리자 계정**에서 모두 할 수 있어요.

- **추가:** 이메일 · 아이디 · 비밀번호(10자 이상) · 권한을 넣고 **＋ 추가** → **지금 게시**
  - 그 아이디·비밀번호를 새 관리자에게 전달하면 바로 로그인할 수 있어요.
- **권한:**
  - **대표 관리자** — 계정 추가·삭제, 비밀번호 재설정, 토큰 교체
  - **관리자** — 내용 수정·게시, 신청 확인, 자기 비밀번호·이메일 변경
- **삭제:** 바로 로그인할 수 없게 돼요. 사이가 틀어져서 뺀 경우라면 안전을 위해 토큰도 새로 바꿔 주세요. (8번)
- **비밀번호를 잊었을 때:** 대표 관리자가 **비밀번호 재설정**으로 새로 정해 줘요.
- **반영 방법:** 계정을 바꾼 뒤에는 **게시**해야 다른 기기에서도 적용돼요.

## 7. 평소에 쓰는 법

**로그인**
- 사이트 맨 아래 **관리자** → 아이디·비밀번호
- 새로고침해도 창을 닫기 전까지는 로그인이 유지돼요.

**고치기**
- **점선 글자:** 눌러서 바로 고쳐요. 경기 스코어와 득점자도 마찬가지예요.
- **목록:** ✎ ↑ ↓ ✕ 버튼과 ＋ 칸으로 추가·삭제해요.
- **사진:** 📷 버튼으로 바꿔요.

**게시하기**
- 고친 내용은 **게시하기**를 눌러야 방문자에게 보여요. 1~2분 걸려요.
- 관리자 막대에 마지막으로 게시한 사람과 시간이 보여요.

**영어**
- 한국어로 고치면 자동으로 번역돼요. 무료 서비스(MyMemory)라 하루 사용량 제한이 있어요.
- 중요한 문장은 EN 화면에서 확인해 주세요.

**영상**
- 창박골 유튜브에 새 영상이 올라오면 자동으로 영상 목록에 나타나요.
- "하이라이트" 영상은 결과가 입력된 경기와 자동으로 연결돼요.

**연습 모드**
- 로그인 창의 **편집 연습**으로 마음껏 고쳐 볼 수 있어요. 게시는 되지 않아요.

## 8. 토큰이 만료됐을 때 (보통 1년에 한 번)

- 사이트는 그대로 보이고, **게시만** 실패해요. GitHub가 만료 전에 이메일로 알려 줘요.
- 대표 관리자가 3번처럼 새 토큰을 만들어요.
- 사이트의 **⚙ 관리자 → 게시 · 이메일 설정 → 토큰 바꾸기**에 넣으면 끝이에요.
- 다른 관리자들은 아무것도 안 해도 돼요.

## 9. 보안 메모

**공개 저장소와 `data.json`은 누구나 볼 수 있어요.** 들어 있는 것은 이렇게 나뉘어요.
- **그대로 보이는 것:** 사이트 내용, 관리자 아이디, 신청서 연결 주소
- **잠긴 상태로만 들어 있는 것:** GitHub 토큰, 관리자 이메일, 신청서 연결 키
  - 열려면 관리자 비밀번호가 필요해요.
- **아예 들어 있지 않은 것:** 비밀번호

**비밀번호는 10자 이상, 다른 곳에서 쓰지 않는 것으로 정하세요.**
- 잠긴 정보는 비밀번호로만 열려서, 쉬운 비밀번호는 뚫릴 수 있어요.
- 뚫리면 사이트 내용이 바뀔 수는 있지만, GitHub 계정이나 돈과는 관계없어요.
- **이상한 변경이 보이면:**
  1. GitHub에서 토큰을 삭제해요.
  2. 저장소 **Commits** 기록에서 이전 버전으로 되돌려요.
  3. 새 토큰을 넣어요.

**신청서 개인정보**
- 신청서 내용(이름·이메일 등)은 회원님 **구글 시트에만** 저장되고 공개 파일에는 들어가지 않아요.

**작성자 이메일 가리기**
- GitHub → Settings → Emails에서 **"Keep my email addresses private"**를 켜 두면 기록에 작성자 이메일이 드러나지 않아요.

## 10. 다른 사람에게 넘겨줄 때 / Claude로 고칠 때

**넘겨줄 때**
- 저장소를 그대로 쓰면서 그 사람에게 **관리자 계정**만 만들어 주면 돼요. (6번)
- 완전히 넘기려면 저장소 **Settings → Transfer ownership**을 쓰고, 새 주인이 3번처럼 토큰을 만들어 **토큰 바꾸기**에 넣어요.

**디자인·기능을 고칠 때**
- `index.html`을 Claude에 첨부하고 원하는 걸 말해요.
- 이렇게 덧붙이면 정확해요: "내용은 data.json과 관리자 모드로 관리되니 디자인·기능만 바꿔줘"
- 고친 파일을 저장소에 같은 이름으로 다시 올리면 돼요. 내용(`data.json`)은 그대로 남아요.
